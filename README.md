# crw（copyReplaceWrite）

基于 Go + Bubble Tea 的 TUI 版本管理工具：把目标文件与同目录下所有 `目标文件名*` 备份
组织成 yazi 风格的双栏窗口（左版本列表 / 右内容预览），回车即可用所选备份内容替换当前文件，
替换前自动为当前内容留档，保证可回退。

## 构建

```bash
go build -o crw .
```

## 使用

```bash
./crw config.yaml
```

## 常用按键

| 按键 | 功能 |
|------|------|
| `j`/`k` | 列表焦点：选择版本；预览焦点：滚动预览（vim 风格） |
| `Tab` / `h` / `l` | 切换焦点（列表 ↔ 预览） |
| `Ctrl+D` / `Ctrl+U` / `PgDn` / `PgUp` | 预览滚动 |
| `F1` | 切换对比模式：当前选中项为母本，预览显示各文件与母本的差异（再按退出） |
| `Enter` | 用选中备份替换当前文件（原内容自动备份，除非已存在相同备份） |
| `c` | 克隆当前内容为新备份（已存在相同备份时跳转到该项） |
| `d` | 删除选中备份（需确认） |
| `D` | 删除选中备份（不确认） |
| `r` | 重新扫描版本列表 |
| `q` | 退出 |

备份命名规则：`config.yaml.bak.20260816_140000`（秒级时间戳，冲突自动加 `_1` 后缀避让）。
